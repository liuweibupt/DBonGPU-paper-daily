An Embedded Ergonomic Posture Monitoring and AI-Assisted Home Learning System on a Raspberry Pi 3B Edge Platform

arXiv 提交 2026-11-25 cs.AR

Truyen T. Le, Vinh Dang Ngoc, Thai Bao Huynh

中文摘要

学生在家独立学习时，常常长时间保持不良坐姿，累计久坐时间过长，并因与学习无关的数字干扰而降低学习效率。此外，学生在自学难度较高的课程时，往往缺少实时的教学支架。为缓解这些人体工学和教学问题，本文提出一套面向家庭学习空间、成本低且保护隐私的嵌入式信息物理系统。该系统基于 Raspberry Pi 3 Model B（1 GB RAM），配备 UVC 光学摄像头和 USB 电容麦克风。系统在设备端利用 MediaPipe Pose 和 OpenCV 运行计算机视觉算法，实时监测上半身姿态对齐情况、矢状面头部倾角和冠状面双肩不对称程度，且不持久保存原始视频流。确定性有限状态机（FSM）统计有效学习时长，确保按健康要求休息，并检测违规使用智能手机的行为。同时，集成的多模态 AI 辅导智能体通过加密 API 网关解析语音和文本提问，生成苏格拉底式的概念提示，避免直接给出答案。轻量级家长网页面板提供加密的学习时段分析结果和日程配置功能。实体原型的基准测试表明，在 352 × 288 分辨率下，端到端推理延迟为 244–250 ms（4.0–4.1 FPS）。在 5,760 个具有真值标注的合成姿态上，躯干角度估计的平均绝对误差（MAE）为 4.39°。系统的常驻内存为 320 MB，持续负载下 SoC 峰值温度为 58.0 °C，离线文本转语音（TTS）反馈路径的总延迟为 1.58 s。这些结果证实了该系统在资源受限边缘设备上部署的实用性。

查看英文原文摘要

During independent home study sessions, students frequently sustain improper sitting postures, accumulate excessive sedentary hours, and experience productivity loss from off-task digital distractions. Furthermore, learners often lack real-time pedagogical scaffolding for demanding self-study curricula. To mitigate these ergonomic and instructional challenges, this paper presents an affordable, privacy-preserving cyber-physical embedded system for domestic study spaces. Engineered on a Raspberry Pi 3 Model B (1 GB RAM) paired with a UVC optical camera and a USB condenser microphone, the system executes on-device computer vision utilizing MediaPipe Pose and OpenCV to monitor upper-body alignment, sagittal head inclination, and coronal shoulder asymmetry in real time without persisting raw video streams. A deterministic finite state machine (FSM) quantifies active study durations, enforces health-compliant rest periods, and detects illicit smartphone usage. Simultaneously, an integrated multimodal AI tutoring agent parses voice and text queries via an encrypted API gateway, synthesizing Socratic conceptual hints rather than direct solutions. A lightweight parental web dashboard delivers encrypted session analytics and scheduling configurations. Empirical benchmarks on the physical prototype confirm an end-to-end inference latency of 244-250 ms at a 352x288 resolution (4.0-4.1 FPS), a trunk-angle estimation error of 4.39 degrees MAE over 5,760 synthetic ground-truth poses, a resident set size of 320 MB, a peak SoC temperature of 58.0 degrees Celsius under sustained load, and a 1.58 s total latency for the offline TTS feedback path, proving high practicality for resource-constrained edge deployment.

核心结论
该系统在配备 1 GB RAM 的 Raspberry Pi 3 Model B 上集成了实时坐姿监测和多模态 AI 辅导。在 352 × 288 分辨率下，端到端推理延迟为 244–250 ms（4.0–4.1 FPS），在 5,760 个合成姿态上的躯干角度估计 MAE 为 4.39°，常驻内存为 320 MB。
创新点
1. 基于 MediaPipe Pose 和 OpenCV 在设备端实时监测上半身姿态、头部倾角和双肩不对称程度，且不持久保存原始视频流；2. 利用确定性有限状态机统计有效学习时长、执行休息规则并检测违规使用手机的行为；3. 通过加密 API 网关处理语音和文本提问，由多模态 AI 辅导智能体生成苏格拉底式概念提示；4. 集成轻量级家长网页面板，提供加密的学习时段分析结果和日程配置功能。

A Differential Computing Accelerator for LLM Inference Leveraging Bit-Slice Transition Sparsity

arXiv 提交 2026-11-25 cs.AR

Yifan Wang, Zetao Guo, You Xiao, Wendi Sun 等 5 人

中文摘要

大语言模型（LLM）已成为现代人工智能的基础。在规模定律的推动下，模型规模迅速增长，给部署带来越来越大的计算和存储压力。为加速占据 LLM 主要计算量的通用矩阵乘法（GEMM）运算，位切片架构沿比特维度拆分量化操作数，以揭示切片级的稀疏性和冗余。然而，现有位切片设计主要利用高位切片的稀疏性，密集的低位切片中仍有大量尚未利用的复用机会。 我们观察到，位切片向量（BSV）在汉明空间中高度聚集，许多 BSV 只需翻转少数几个比特，就能与少量代表性模式中的某一个相匹配。基于这一观察，我们提出算法与硬件协同设计的加速器 ISTS，将代表性 BSV 模式用作共享的斯坦纳点（Steiner points），在切片之间复用部分和，从而大幅减少计算量。具体而言，只需进行少量加减运算，即可从分配给目标 BSV 的斯坦纳点的部分和重建该目标 BSV 的部分和。在算法方面，我们提出斯坦纳吸收表构建方法（Steiner Absorption Table Construction，SATC），选取一组精简的斯坦纳点，使其仅需少量双向比特翻转即可吸收 BSV。FlipPrune 则选择性地剪除部分翻转，进一步扩大可参与复用的 BSV 集合。在硬件方面，我们设计了轻量级加速器，支持对静态线性层权重和运行时生成的注意力 K/V 张量进行基于斯坦纳点的复用。综合评估表明，ISTS 相比先进加速器 ANT、BBS、LUT Tensor Core、Transitive Array 和 MCBP-BRCR 的平均加速比分别为 3.09×、2.41×、2.18×、1.27× 和 1.41×。

查看英文原文摘要

Large language models (LLMs) have become foundational to modern artificial intelligence. Driven by scaling laws, their rapid growth poses increasing computational and memory challenges for deployment. To accelerate the general matrix multiplication (GEMM) operations that dominate LLM computation, bit-slice architectures decompose quantized operands along the bit dimension, exposing slice-level sparsity and redundancy. However, existing bit-slice designs primarily exploit sparsity in high-order slices, while dense low-order slices still offer substantial untapped reuse opportunities. We observe that bit-slice vectors (BSVs) are highly clustered in Hamming space, with many BSVs lying only a few bit flips away from a small set of representative patterns. Based on this observation, we propose ISTS, an algorithm-hardware co-designed accelerator that leverages representative BSV patterns as shared Steiner points to reuse partial sums across slices, substantially reducing computation. Specifically, the partial sum of each target BSV can be reconstructed from that of its assigned Steiner point using only a few additions or subtractions. On the algorithmic side, we propose Steiner Absorption Table Construction (SATC), which selects a compact set of Steiner points to absorb BSVs with only a few bidirectional bit flips, while FlipPrune selectively prunes flips to further expand the reusable BSV population. On the hardware side, we design a lightweight accelerator that supports Steiner reuse for static linear layer weights and runtime-generated attention K/V tensors. Comprehensive evaluations show that ISTS achieves average speedups of $3.09\times$, $2.41\times$, $2.18\times$, $1.27\times$, and $1.41\times$ over the state-of-the-art accelerators ANT, BBS, LUT Tensor Core, Transitive Array, and MCBP-BRCR, respectively.

核心结论
ISTS 利用位切片向量在汉明空间中的聚集性，通过少量加减运算复用部分和，并支持静态线性层权重及运行时生成的注意力 K/V 张量。相比 ANT、BBS、LUT Tensor Core、Transitive Array 和 MCBP-BRCR，ISTS 的平均加速比分别为 3.09×、2.41×、2.18×、1.27× 和 1.41×。
创新点
1. 提出 ISTS，将代表性位切片向量用作共享斯坦纳点，以少量加减运算重建目标向量的部分和，实现跨切片复用；2. 提出 SATC，选取可通过少量双向比特翻转覆盖多个位切片向量的精简斯坦纳点集合；3. 提出 FlipPrune，选择性剪除部分翻转以扩大可复用的向量集合；4. 设计轻量级加速器，支持对静态线性层权重和运行时生成的注意力 K/V 张量进行斯坦纳点复用。

High-Throughput GPU Decoding of Quantum Bivariate Bicycle Codes under Circuit-Level Noise

arXiv 提交 2026-11-25 cs.AR quant-ph

Aditya Sodhani, Keshab K. Parhi

中文摘要

与表面码等其他量子纠错码相比，双变量自行车码（bivariate bicycle，BB 码）可减少量子纠错所需的物理量子比特开销，但电路级故障会在测量轮次之间引入依赖，限制解码吞吐量。我们提出一种并行窗口 GPU 解码器，结合可复用的故障模式、紧凑的共享内存状态和常驻 GPU 工作单元，采用最小和算法进行解码，并以 Relay-BP 执行恢复。在 RTX 5090 上，对于所评估的全部 4 种码（最大至 [[144,12,12]]），所提解码器均能跟上每 1 μs 一轮综合征的节奏，提交延迟中位数为 63–144 μs。以往的电路级 GPU 解码研究尚未达到这一速率，该解码器的吞吐量是顺序滑动窗口解码的 120 倍。在接受解码结果前检查相邻探测器轮次，最多可将失败率降低 65%。当 p = 0.002 时，所提解码器在 [[144,12,12]] 码上的每轮失败率为 7.58 × 10⁻⁶，比已发表的带综合征翻转的置信传播（BP-SF）结果低 36%。

查看英文原文摘要

Bivariate bicycle (BB) codes reduce the physical-qubit overhead of quantum error correction compared to other codes such as Surface codes, but circuit-level faults create dependencies across measurement rounds that limit decoding throughput. We present a parallel-window GPU decoder that combines reusable fault patterns, compact shared-memory state, and persistent GPU workers using min-sum with Relay-BP recovery. On an RTX 5090, the proposed decoder keeps pace with one syndrome round every 1 $μ$s across all four evaluated codes, up to [[144,12,12]] with 63-144 $μ$s median commit delays. This rate has not been demonstrated in prior circuit-level GPU decoding studies and it provides $120\times$ higher decoding throughput than sequential sliding-window decoding. Checking neighboring detector rounds before accepting a decoding result reduces failure rates by up to 65%. For [[144,12,12]] at $p=0.002$, our proposed decoder achieves $7.58\times 10^{-6}$ failures per round, 36% lower than the published belief propagation (BP) with syndrome flipping (BP-SF) result.

核心结论
在 RTX 5090 上，该解码器对全部 4 种受测 BB 码（最大至 [[144,12,12]]）均能跟上每 1 μs 一轮综合征的节奏，提交延迟中位数为 63–144 μs，吞吐量为顺序滑动窗口解码的 120 倍。对 [[144,12,12]] 码，在 p = 0.002 时，每轮失败率为 7.58 × 10⁻⁶，比已发表的 BP-SF 结果低 36%。
创新点
1. 设计并行窗口 GPU 解码器，结合可复用故障模式、紧凑的共享内存状态和常驻 GPU 工作单元，并采用最小和算法与 Relay-BP 恢复；2. 在接受解码结果前检查相邻探测器轮次，以降低失败率。

DiversePlace: Diversity-Seeking Curriculum Reinforcement Learning for Macro Placement

arXiv 提交 2026-11-25 cs.AR cs.LG

Wenrui Zhou, Jiashun Liu, Wenji Fang, Zhiyao Xie 等 5 人

中文摘要

宏单元布局是物理设计早期的关键决策，因为宏单元的位置会对后续实现阶段施加强约束。其难点在于，这些影响重大的离散决策必须在下游实现质量能够得到准确评估之前完成，训练因而依赖半周长线长（HPWL）等快速但不完全准确的评估指标。因此，现有基于强化学习（RL）的布局器大多以 HPWL 为驱动优化单个方案，且由于顺序决策跨度长，通常需要大量搜索辅助或离线专家数据，难以保留多个有竞争力的布局。我们将质量约束下的多样性设为宏单元布局的显式目标，以弥补这一不足。我们维护一个精简的布局档案，供下游选择，其中各布局在 HPWL 上均具有竞争力，且彼此存在实质差异。DiversePlace 将这一思路实现为基于近端策略优化（PPO）的课程学习框架，将由质量门槛控制的多样性奖励与逐步扩展的布局决策跨度相结合，使强化学习能够从零开始优化，同时将探索限制在 HPWL 具有竞争力的区域内。在 ISPD2005 基准上，DiversePlace 一贯提高了前 5、前 10 和前 20 个归档布局的多样性，在全部 8 个设计上均取得了更低或几乎相同的 HPWL，并且效率更高。代码见 https://github.com/William030422/NIPS2026-DiversePlace。

查看英文原文摘要

Macro placement is a critical early-stage decision in physical design because macro locations strongly constrain subsequent implementation stages. The task is difficult because these high-impact discrete decisions must be made before downstream quality can be measured accurately, forcing training to rely on fast but imperfect training-time oracles such as half-perimeter wirelength (HPWL). Existing RL-based placers therefore mostly optimize single HPWL-driven solutions, and their long sequential horizons often require heavy search assistance or offline expert data while leaving little room to preserve multiple competitive layouts. We address this gap by making quality-controlled diversity an explicit objective for macro placement. Instead of relying on a single proxy-optimal solution, we maintain a compact archive of HPWL-competitive yet meaningfully different placements for downstream selection. We realize this idea in DiversePlace, a curriculum proximal policy optimization (PPO) framework that combines a quality-gated diversity reward with an expanding placement horizon, enabling from-scratch RL optimization while keeping exploration inside competitive HPWL regions. On the ISPD2005 benchmarks, DiversePlace consistently improves top-5, top-10, and top-20 archive diversity and achieves lower or virtually identical HPWL on all eight designs with better efficiency. Code: https://github.com/William030422/NIPS2026-DiversePlace.

核心结论
在 ISPD2005 的全部 8 个设计上，DiversePlace 均取得更低或几乎相同的 HPWL，且效率更高，同时稳定提升了前 5、前 10 和前 20 个归档布局的多样性。摘要未指明这些结果所对比的具体基线。
创新点
1. 将质量约束下的多样性设为宏单元布局的显式目标，维护一个兼顾 HPWL 竞争力与实质布局差异的精简档案，供下游选择；2. 提出基于 PPO 的课程学习框架，将由质量门槛控制的多样性奖励与逐步扩展的布局决策跨度相结合，使强化学习可从零开始优化，并将探索限制在 HPWL 具有竞争力的区域内。

Any-Rate: Half-Bit Multi-Precision LLM Quantization with Coded Bit-Planes

arXiv 提交 2026-11-25 cs.AR cs.LG cs.CL

Hoonki Lee, Haechan Shin, Hyuntaek Jung, Yeonu Choi 等 5 人

中文摘要

嵌套式多精度量化只需读取每个权重的高位比特，即可从单个模型检查点获得多种精度，因此适合在内存和能耗预算各异的设备上部署。然而，现有方法仅支持整数位宽，相邻精度之间的准确率差距较大，且在 2 比特下准确率严重下降。为此，我们提出 Any-Rate，它从单个检查点支持 2–8 比特，并在 2–4 比特范围内提供 0.5 比特的步长。Any-Rate 将权重按每 8 个一组分块，把部分位平面约束为扩展汉明码码字（每个权重 0.5 比特），让各精度共享每行的同一张查找表（LUT），并为每种精度设置独立目标，对所有精度进行联合编码，从而减少共享位平面带来的损失。在 4 个 LLM 上，Any-Rate 在 2 比特和 3 比特下的准确率达到多精度方法的领先水平，在 2 比特下保留了 FP16 准确率的 69%，在 4 比特下与最佳结果的差距不超过 1 个百分点。其解码速度与现有内核大致相当。LPDDR 能耗模型估算表明，在准确率相同的条件下，能耗最多可降低 27%。代码见 https://github.com/hoonki2002/Any-Rate。

查看英文原文摘要

Nested multi-precision quantization derives multiple precisions from a single checkpoint by reading only the leading bits of each weight, which makes it attractive for on-device deployment under varying memory and energy budgets. However, existing methods offer only integer bits, leaving large accuracy gaps between adjacent precisions and severe degradation at 2 bits. To address this, we propose Any-Rate, which serves 2-8 bits from one checkpoint, in half-bit steps over 2-4 bits. Any-Rate restricts some bit-planes to extended Hamming codewords in 8-weight blocks (0.5 bits per weight), shares one LUT per row across precisions, and encodes all precisions jointly with a separate target for each, reducing the loss from sharing bit-planes. Across four LLMs, Any-Rate achieves state-of-the-art accuracy among multi-precision methods at 2 and 3 bits, keeping 69% of FP16 accuracy at 2 bits, and is within one point of the best at 4 bits. It decodes about as fast as existing kernels, and an LPDDR energy model estimates up to 27% less energy at equal accuracy. Code is available at https://github.com/hoonki2002/Any-Rate.

核心结论
Any-Rate 从单个检查点支持 2–8 比特量化，并在 2–4 比特间提供 0.5 比特步长。在 4 个 LLM 的评估中，其 2 比特和 3 比特准确率在多精度方法中领先，2 比特保留了 FP16 准确率的 69%，4 比特与最佳结果相差至多 1 个百分点，且解码速度与现有内核大致相当。LPDDR 模型估算，同等准确率下能耗最多可降低 27%。
创新点
1. 按每 8 个权重分块，将部分位平面限制为扩展汉明码码字，实现每权重 0.5 比特的编码粒度；2. 在不同精度间共享每行的同一张查找表；3. 为每种精度设置独立目标并联合编码所有精度，以减少共享位平面带来的损失。

MixMoMo: Accelerating Extra--Large MoE Inference with Mixed--Precision GPU--NPU Execution on Mobile Devices

arXiv 提交 2026-11-25 cs.AR

Hailong Zou, Maoliang Li, Taohong Han, Haoze Chi 等 7 人

中文摘要

移动智能体和端侧智能应用对智能手机上运行的模型提出了更高的能力要求。混合专家（MoE）模型通过稀疏激活专家来扩展模型容量，但随着细粒度专家数量增长，加载和计算变得更加复杂。模型压缩可降低存储和计算开销，与专家卸载形成互补。混合精度量化是一种模型压缩技术，通过为部分专家分配较低位宽来平衡模型质量与推理效率。然而，现有离线指标和路由分数无法反映专家对量化的敏感性，影响位宽分配的效果。不同位宽也增加了在执行特性各异的 GPU 和 NPU 之间均衡分配专家的难度，而逐分块反量化无法充分利用 NPU 的向量并行能力。我们提出 MixMoMo，一种面向异构移动 SoC 上超大规模 MoE 模型的高效混合精度推理运行时。MixMoMo 将离线量化影响剖析结果与基于激活的运行时风险估计相结合，在质量约束下分配专家位宽。它还采用按精度组织的执行方式，在 GPU 和 NPU 之间均衡分配专家，并通过 HVX 并行反量化充分利用 NPU 的向量并行能力。在 2 个移动平台上使用 3 个 MoE 模型和 5 项基准进行评测，MixMoMo 相对于统一采用 Q4_0 的基线和表现最强的混合精度 MoE 基线，分别实现了 3.72 倍和 1.53 倍的平均解码加速。

查看英文原文摘要

Mobile agents and on-device intelligence increasingly demand more capable models on smartphones. Through sparse expert activation, Mixture-of-Experts (MoE) scales model capacity, yet growing numbers of fine-grained experts complicate loading and computation. Model compression complements expert offloading by reducing storage and computation costs. Among compression techniques, mixed-precision quantization assigns lower expert bitwidths to balance model quality and inference efficiency. However, existing offline metrics and routing scores fail to reflect expert quantization sensitivity, undermining precision assignment. Diverse bitwidths also complicate balanced expert allocation across GPUs and NPUs with distinct execution characteristics, while tile-wise dequantization underutilizes NPU vector parallelism. We present MixMoMo, an efficient mixed-precision inference runtime for extra-large MoE models on heterogeneous mobile SoCs. MixMoMo combines offline quantization-impact profiles with activation-based runtime risk estimates for quality-constrained expert bitwidth assignment. It further adopts precision-structured execution for balanced GPU-NPU expert allocation and HVX-parallel dequantization for efficient NPU vector utilization. Across three MoE models and five benchmarks on two mobile platforms, MixMoMo achieves average decoding speedups of 3.72x over uniform Q4_0 and 1.53x over the strongest mixed-precision MoE baseline.

核心结论
在 2 个移动平台、3 个 MoE 模型和 5 项基准的评测中，MixMoMo 相对统一 Q4_0 基线和表现最强的混合精度 MoE 基线，分别实现了 3.72 倍和 1.53 倍的平均解码加速。
创新点

中文摘要

代数分集将对多个观测求平均的思想推广到对单个观测在与其结构匹配的变换群上求平均。本文在布尔立方体 𝔽₂ⁿ 上建立这一框架，涵盖平移群、坐标置换群、超八面体群、一般线性群和仿射群。本文确定了每种群作用的对易代数，并给出单张真值表经群平均后的二阶统计量的闭式表达。对平移群，该统计量归结为沃尔什周期图。对超八面体群，它归结为按汉明重量分组的平均值。对仿射群，它归结为在整体取反等价意义下的汉明重量。弯曲函数（bent functions）恰好是平移平均结果呈白谱的函数。按给定输入顺序进行的 Haar 变换对应于香农展开的多路复用器树。高阶平均在达到首个能提供超出汉明重量的信息的阶数之前，只能反映汉明重量。这一阶数对平移群为 2，对仿射群为 4。与函数相匹配的稳定子群可替代重复观测，因为在大小为 s 的轨道上进行投票，可使达到目标误差所需的含噪真值表数量降至原来的 1/s。同一视角还将函数的仿射包用作匹配坐标，给出了 XOR 哈希的精确方差恒等式，并构造出方差始终不超过成对独立哈希的匹配哈希。在公开基准上的应用包括为近似模型计数选择哈希方法，利用子句块的谱判定具有奇偶结构的公式并反驳模 3 和模 4 的计数公式，利用规范谱区分 NPN 等价类并在 ISCAS-85 电路的割函数和全部 5 输入等价类上进行测试，利用对称性投票纠正含噪真值表并保护查找表，进行盲群匹配，以及构造一种类似 CLEAN 的算法，将真值表表示为各群不动子空间中原子的异或。本文给出了所有证明的完整过程。

查看英文原文摘要

Algebraic Diversity generalizes averaging over many observations to averaging one observation over a group of transformations matched to its structure. This paper develops the framework on the Boolean cube $\mathbb{F}_2^n$ for the translations, the coordinate permutations, the hyperoctahedral group, and the general linear and affine groups. It determines the commutant of each action and gives closed forms for the group-averaged second-order statistic of one truth table, which collapses to the Walsh periodogram for the translations, to per-weight averages for the hyperoctahedral group, and to the weight up to complementation for the affine group. Bent functions are exactly those whose translation average is white, the Haar transform along an input order is the multiplexer tree of Shannon's expansion, and higher-order averages see only the weight below a first informative order, two for the translations and four for the affine group. A matched stabilizer stands in for repeated observations, since a vote over orbits of $s$ points divides by $s$ the number of noisy truth tables a target error requires. The same viewpoint gives the affine hull of a function as matched coordinates, an exact variance identity for XOR hashing, and matched hashes whose variance never exceeds that of a pairwise independent hash. Applications on public benchmarks include hash choice for approximate model counting, the decision of parity-structured formulas and the refutation of counting formulas modulo 3 and 4 from the spectra of clause blocks, separation of NPN classes by canonical spectra, tested on ISCAS-85 cut functions and all five-input classes, correction of noisy truth tables and protection of lookup tables by voting over symmetries, blind group matching, and an analog of the CLEAN algorithm that writes a truth table as the XOR of atoms in the fixed spaces of groups. All proofs are given in full.

核心结论
